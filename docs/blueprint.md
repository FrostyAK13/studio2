# **App Name**: SignalPulse

## Core Features:

- Stock Symbol Input: Allow users to enter a specific stock ticker symbol (e.g., AAPL) for analysis.
- Date Range Selection: Provide intuitive date pickers for users to specify a historical period ('from' and 'to' dates) for data retrieval.
- Historical Price Data Fetching: Integrate with a third-party financial API to retrieve historical stock prices and trading volumes for the specified symbol and date range.
- Interactive Price Chart: Display the fetched historical stock prices and trends on an interactive line chart.
- Offline Signal Management: Allow the app to process and generate signals based on local data and predefined rules, storing them locally. These signals are queued for transmission to the server and will be sent automatically upon network restoration, ensuring that no signal is lost due to temporary connectivity issues.

## Style Guidelines:

- The primary color, representing professional analysis and clarity, is a steel blue (#336699). It is strong enough to stand out against a light background without being overly bold.
- The background color is a very light, desaturated cool gray-blue (#F2F6F9), ensuring high readability for data and charts in a bright, analytical interface.
- An accent color of vibrant royal purple (#664CD8) is used to draw attention to interactive elements and highlight key information on the charts, creating visual interest.
- Body and headline font: 'Inter' (sans-serif) for its modern, objective, and highly readable characteristics, suitable for presenting financial data and analytical insights.
